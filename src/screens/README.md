# Pantallas

Cada carpeta contiene una pantalla independiente del flujo web definido en Figma.

- `w01-dashboard`: Inicio.
- `w02-planning`: Planificación semanal.
- `w03-create-alert`: Crear alerta.
- `w04-routines`: Rutinas.
- `w05-locations`: Ubicaciones guardadas.
- `w06-integrations`: Integraciones.
- `w07-history`: Historial.
- `w08-cleanup`: Depuración de alarmas.
- `w09-settings`: Configuración.
- `w10-templates`: Plantillas.

Los componentes reutilizables deben vivir en `src/components` y las rutas se
mantienen centralizadas en `src/app/routes.ts`.
